# 콩 상점 도구 카드 이미지 프레이밍 수정

## 문제

모바일 콩 상점의 `콩쥐 도구` 2×2 카드에서 나무/놋쇠 바가지는 비교적 정상으로 보이지만, 청자 바가지는 밝은 사각형 조각이 잘려 들어오고 월광 바가지는 우측으로 치우쳐 작게 보인다.

## 원인

상점 상품 카드가 제품 썸네일이 아니라 퀴즈 장면용 `pour-sheet.png`를 배경 스프라이트로 사용하고 있었다. 현재 도구 동작 시트는 4096×768이며 8개의 512×768 프레임으로 구성되어 있는데, 상점 CSS는 이를 512×512 셀처럼 취급하면서 `aspect-ratio: 1 / 1`, `background-size: 800% 100%`, 추가 확대 및 `translateY(-21%)`까지 적용했다. 이 때문에 게임 장면용 기준점/여백이 제품 카드에 노출되어 도구별 잘림과 위치 편차가 발생했다.

## 해결 지침

1. 상점 카드와 카테고리 미리보기는 게임 애니메이션 시트가 아니라 기존 제품용 PNG를 직접 사용한다.
   - `assets/art/kongjwi-tools/wood.png`
   - `assets/art/kongjwi-tools/brass.png`
   - `assets/art/kongjwi-tools/celadon.png`
   - `assets/art/kongjwi-tools/moon.png`
2. 네 PNG의 공통 원본 비율인 320×200(8:5)을 유지한다.
3. `background-size: contain`, 중앙 정렬을 사용하고 강제 확대/세로 이동/스케일 보정을 제거한다.
4. 카드의 기존 2열 모바일 레이아웃, 구매/장착 로직, 게임 장면의 4096×768 동작 시트는 변경하지 않는다.
5. 기존 심볼 placeholder `::before`는 실제 도구 이미지 위에 나타나지 않도록 계속 비활성화한다.
6. CSS 캐시 버전을 갱신한다.

## 완료 조건

- 4종 도구가 모두 카드 안에서 완전한 형태로 중앙 정렬된다.
- 청자 바가지의 밝은 사각형/잘린 조각이 보이지 않는다.
- 월광 바가지가 우측으로 치우치지 않는다.
- 이미지 비율이 찌그러지지 않는다.
- 도구 상품 카드 CSS에서 `pour-sheet.png`, `800%` 스프라이트 확대, `translateY`, `scale()` 보정이 다시 사용되지 않는다.
- `tests/shop-tool-card-layout.test.mjs`가 통과한다.
